# Dataset

Place the concrete mixture dataset at:

```text
data/concrete_strength_data.csv
```

The dataset used for this project was compiled from 39 published articles and contains 1,143 green concrete mixture records. It includes mixture proportions, curing age, specimen properties, and measured compressive strength.

The associated article is:

Maherian et al. (2023), Construction and Building Materials, 408, 133684. https://doi.org/10.1016/j.conbuildmat.2023.133684

The dataset is not included in this repository. It can be made available upon reasonable request.
